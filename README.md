# Snored Art Online 攻略資料庫

任務素材掉落率、魔王掉落、裝備圖鑑、獨特技能、樓層情報與攻速 500 試算。

網站網址：https://chiaomao666.github.io/snored-art-online-site/

攻略前端由 GitHub Actions 驗證並發布到 GitHub Pages。帳號查詢另由 Cloudflare Worker 提供，使用遊戲帳密登入會中斷原遊戲連線。

## 收錄內容

- 樓層情報與秘境詳解保留基礎獎勵，另依共用角色等級、實際分配人數（含自己）及可選個人折減，計算個人經驗與摳及其排序。人數倍率為 (1+0.05*(N-1))/N；2、5、6 人已有實測，3、4 人標為待驗證。低等折減與額外經驗 10% 只在勾選時套用，不自動判定觸發門檻。

- 怪物圖鑑：589 種怪物的能力、地點、完整可能掉落與基礎機率（只顯示基礎經驗與摳，不放個人試算）；另含 40 層頭目招式、血量階段、蓄力與冷卻，支援用裝備或素材名稱反查來源；另列 6 種主線專屬怪物的章節步驟、出現條件與隱藏區域。

- 配裝模擬器：八部位配裝、逐件強化分配、勾選匠魂自動套用單手槌與盾牌強化加成、能力總覽、依主線章節自動計算永久加成、獨特技能常駐設定、身上暫時增益、已有裝備的部分匠魂強化紀錄與分享連結。

- 五種武器的 30 招攻擊與 15 招增益技能：角色等級、前置技能 Lv3、Lv1～Lv10 倍率／冷卻／目標與附加效果，並比較增益熟練前後差異。

- 22 件獨特類任務道具：19 件收集掉落物與 3 件劇情／狀態道具。
- 40 層魔王、121 件第 1～40 層頭目裝備；41～75 層另外保留舊檔定義備註。
- 466 件裝備，含 188 把武器與 50 面盾牌，保留全部基礎能力。
- 五種獨特技能的舊版性能、修行步驟與等級條件。
- 196 個一般區域、40 個秘境、40 個頭目房：583 種怪物的單隻基礎經驗與摳、各區同屏上限和每批數量；秘境另列怪物性能與素材／通用物品掉落設定。
- 無暫時增益／自身全開的攻速敏捷門檻；可輸入強化後武器攻速。

## 本機預覽

在 repository 根目錄啟動任意靜態伺服器，例如：

```sh
python -m http.server 8080
```

開啟 `http://localhost:8080/`。此網站不需安裝前端套件。

## 修改資料

主要整理資料放在 `guide-data.json`。修改後執行：

```sh
node build-data.cjs
node validate.cjs
```

`data.js` 是給瀏覽器直接載入的同一份資料。請一併提交 JSON 與更新後的 data.js。原始遊戲下載檔不放入本 repository。`monster-data.js` 是另外整理的怪物能力與掉落資料，`monster-checks.cjs` 會驗證與樓層資料一致，以及所有掉落物引用、機率和頭目池設定。

## 資料依據與限制

資料快照：2026-10-24。裝備、任務收集設定、地圖與攻速以提供的 `main-CqsPH2Ju.js` 和 `main-Bril-Iat.js` 為依據；任務中文名稱和獨特技能性能參考 `guide-DkE4QRtb.js` 以及前次經驗算的整理。兩份 main 檔使用先前完成語法修復的副本，未覆寫原始檔。

任務素材百分比是 collect 目標的 chance 設定，並非稀有怪的生成率；前端未提供完整伺服器掉落與分配實作，不能據此保證提前囤貨、離線調整或多人分配規則。三件劇情／狀態道具不填怪物掉落率。期望擊倒數與機率試算假設各次獨立、成功取得一件，不代表保底。

魔王專屬池的 8% 是整個池的觸發率；單件的抽選機率未提供，沒有直接寫成 8% 或 8% ÷ 3。

獨特技能的舊版固定門檻、被動與招式數值僅作版本參考。Cqs 版將 UNIQUE_KILLS、DUAL_SPEED 等參數移到伺服器，不能把本地預設 0 當成正式數值。攻速工具可手動調整二刀流被動。敏捷公式、400ms 間隔下限與取整方式在兩份 main 檔相同。

## GitHub Pages

在 repository 的 Settings → Pages，將 Source 設為 **GitHub Actions**。`.github/workflows/deploy.yml` 會在 main 分支更新時自動檢查 JavaScript、重建瀏覽器資料、執行資料驗證，然後把通過檢查的 `_site/` 發布到 GitHub Pages。也可在 Actions → Validate and deploy guide → Run workflow 手動重新發布。Pull request 只檢查，不部署。



網站檔案統一放在根目錄，便於直接從 GitHub 的 Upload files 更新；不需安裝套件或額外建置。

## 經驗與等級差

2026-10-26 以單人 WebSocket 擊殺獎勵核對：角色 Lv57–58、12 種 Lv7–61 怪物（含第1、2、3、35層單人頭目）的每隻經驗均吻合 Math.round(baseExp * Math.max(0.01, 0.75 ** Math.max(0, playerLevel - monsterLevel - 5)))。先從基礎經驗計算，再四捨五入，不拿前一級已取整的實得值繼續乘。此規則亦與檔案的 lowExpGrace=5、lowExpBase=0.75 一致。

reward-guide.js 是共用計算與顯示模組；樓層表、秘境卡與怪物圖鑑分列基礎經驗、推估倍率和單人經驗推估。兩頁共用角色等級，另提供推估經驗排序。測試涵蓋 16 組實測對照、寬限邊界、取整順序、無效／隱藏等級和延伸推估。

公式顯示為推估；其他等級／怪物屬延伸推估。組隊、活動、離線、多人頭目分配與特殊獎勵、高等怪可能的上限均未推定。最低 1% 是倍率下限，最後仍四捨五入；沒有另行假設最少 1 點經驗。小基礎經驗可能取整為 0，此情境未直接實測。摳不套用經驗衰減倍率。個人擊殺歷史、角色名稱、憑證與監測原始檔不發布。

## 帳號查詢

`account-ui.js` 與 `account-model.js` 是查詢畫面及顯示計算，`account-worker.mjs` 是 Cloudflare Worker 後端（不包含在 Pages 公開資產中）。

- 唯一查詢入口為 POST `/query`；固定連到遊戲 `/api/link`、`/api/me`、`/api/ws`，不接受自訂目標或遊戲命令。
- 不帶角色名稱註冊、不變更密碼、不重生；已死亡帳號只列角色紀錄。
- 登入後只讀取第一份 init 快照，成功、失敗或逾時都關閉 WebSocket；不自動重連。
- 帳密與憑證不寫入儲存或程式日誌；憑證不回傳前端。回應禁止快取。前端只在目前分頁記憶體保留角色結果。
- 回傳白名單角色欄位，不回傳聊天、信箱、好友、戰鬥紀錄、帳號名稱或登入憑證。
- CORS 僅允許 `https://chiaomao666.github.io`；Worker 有每個執行個體的基本頻率限制，不應視為全域限流。大量使用時應搭配 Cloudflare 全域限流。
- 裝備性能仍依攻略快照與匠魂效果 +25% 計算，包含實際的逐方向匠魂強化次數；未收錄的新裝備不推測數值。
- 測試：`node account-worker-checks.mjs`、`node validate.cjs`。
- Worker 由 Cloudflare 編輯器部署；查詢功能不需要資料庫或任何持久化憑證。

### 背包篩選與裝備明細

`account-inventory.js` 提供背包種類、部位、武器類型、品質、強化篩選與排序，每頁 12 筆。`account-model.js` 合併堆疊背包與未裝備的獨立 gear，保留同名裝備的不同強化。Cloudflare Worker v3 回傳完整 owned gear 的安全欄位，含 tries、smithTries、hist。剩餘次數明確標為裝備紀錄，不推測尚未啟用的匠魂額外機會；逐次歷史不保證包含舊版全部紀錄。強化指數指裝備的 +N，沒有另創評分。


### 最低倍率 1%

Lv58 單人打第1、2、3層頭目，基礎經驗390、450、582，最低保留1%後四捨五入為4、5、6；第35層頭目4038基礎經驗乘0.75的3次方後為1704，均與紀錄一致。


## 配裝分享連結

新連結使用 `#build?b=1.…` 精簡編碼，完整保存裝備、強化方向、主線章節、獨特技能和自訂參數。舊 JSON 連結仍可讀取。連結自行包含配裝，不需要短網址後端或登入；固定版本的裝備與章節代碼表不能重新排序。新裝備 ID 有內嵌編碼備援。
